隱私與掌控

你的工作區，清楚的邊界。

知道工作儲存在哪裡，也知道自己授權了什麼。本機儲存、線上模型與連接工具，各有各的作用。

規劃 · 執行 · 審閱

先留一點思考的空間。

規劃與審閱會在執行前阻止檔案修改。執行模式依所選核准政策開放操作；已核准的 Shell 指令和你開啟的終端機，使用目前桌面使用者權限。

規劃審閱唯讀邊界執行
01

本機上下文

儲存在裝置上，也說明何時會傳送。

專案與對話紀錄儲存在本機。相關提示、檔案和工具結果仍可能傳送至你選擇的模型或已連接服務。

02

憑證

交給作業系統保護。

API 金鑰與連線憑證使用作業系統加密。保護不可用時拒絕儲存機密資訊；這不代表所有檔案與對話均已加密。

03

工具與擴充功能

每一種工具，有自己的權限。

本機 MCP 服務預設使用原生隔離，可個別設定網路和相容模式。可執行擴充功能需要明確信任；完整本機存取設定僅影響擴充功能。

04

IM 授權

在選定的範圍裡，共享工作。

為不同接收方授權專案、資料夾或檔案。寫入、指令與網路權限分別管理；加入群組本身，不會取得你的電腦存取權。

了解之後，再連接。

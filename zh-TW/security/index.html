隱私與掌控

你的工作區，清楚的邊界。

知道工作儲存在哪裡，也知道自己授權了什麼。本機儲存、線上模型與連接工具，各有各的作用。

Plan · Work · Codemode

先留一點思考的空間。

唯讀調查、分析與審閱，不修改檔案。Plan 不執行 Shell、MCP 或可執行擴充；由你決定何時開始執行。 依所選核准策略修改檔案、執行工具、推進任務。Work 是新任務的預設模式。 透過指令碼串聯工具，完成多步驟工作。Codemode 與 Work 使用相同的權限與核准邊界。

本機上下文

01

儲存在裝置上，也說明何時會傳送。

專案與對話紀錄儲存在本機。相關提示、檔案和工具結果仍可能傳送至你選擇的模型或已連接服務。

憑證

02

交給作業系統保護。

API 金鑰與連線憑證使用作業系統加密。保護不可用時拒絕儲存機密資訊；這不代表所有檔案與對話均已加密。

工具與擴充功能

03

每一種工具，有自己的權限。

本機 MCP 服務預設使用原生隔離，可個別設定網路和相容模式。可執行擴充功能需要明確信任；完整本機存取設定僅影響擴充功能。 獲准的 Shell 命令與整合終端機使用桌面使用者權限。本機 MCP 預設隔離；有理由且獲准的單次權限提升不會改變已儲存的權限設定。

IM 授權

04

在選定的範圍裡，共享工作。

為不同接收方授權專案、資料夾或檔案。寫入、指令與網路權限分別管理；加入群組本身，不會取得你的電腦存取權。

隱私權政策

工作區儲存在你的裝置上。連接帳戶或使用線上模型，也會涉及你選擇的服務。本政策說明這些資料邊界。

1. 適用範圍與營運者

Eureka Raider 提供 Artemis 桌面 AI 代理工作區及本網站。本政策涵蓋透過 Artemis、Google 整合及支援管道處理資訊的方式。第三方服務另適用其自身政策。

2. Artemis 存取的資訊

Artemis 處理你提供或授權存取的提示、檔案、專案內容、工具結果及對話紀錄。使用所選服務也需要模型設定及已連接帳戶的憑證。

連接 Google 後，Artemis 會存取帳戶識別碼、電子郵件及個人資料來辨識帳戶。依連接器及核准權限，可能存取 Gmail 內文、標頭、收件人、附件、草稿及標籤；Google Drive 檔案內容與中繼資料，包括文件、試算表及簡報；以及 Google Calendar 日曆、活動、參與者與空閒時間。Google 授權畫面會列出要求的權限。

3. Google 權限的用途

Gmail 權限用於按要求尋找、閱讀、草擬、傳送及整理郵件。Drive 權限用於尋找、閱讀、建立及更新檔案。Calendar 權限用於查詢行程及建立、更新或刪除活動。操作取決於服務提供的工具及你的指示。

Google 連線是選用功能。資料只用於你要求的連接功能，不用於廣告、廣告側寫或信用決策，也不出售。

4. 模型服務及其他接收方

使用 Google 資料時，相關郵件、檔案、日曆及工具結果可能納入對話，傳送至你設定的 AI 服務商以完成任務。本機優先不代表所有處理都在裝置內；使用敏感內容前，請選好服務商及保留設定。

工具或外掛服務接收執行授權操作所需的資料。傳送郵件、分享檔案或發布內容也會向指定收件人披露內容。裝置直接與 Google 及所設定服務通訊；本網站不接收 Google 授權權杖。

Google 資料僅能在你同意下為提供要求的功能傳輸，或因必要安全措施、法律要求而傳輸；涉及營運主體移轉，須事先取得你的明確同意。

5. Google API 資料與有限使用

Artemis 使用和傳輸 Google API 資訊時，遵循 Google API Services User Data Policy 及其 Limited Use（有限使用）要求。

Google 使用者資料不用於開發、改進或訓練通用 AI 或機器學習模型。以模型處理內容來回答你的要求不等於訓練；請僅選用遵守這些限制的服務商與設定。

我們不會例行閱讀 Google 使用者資料。人工存取僅限你明確同意的特定資料、必要安全調查、法律義務，或 Google 政策允許的彙總內部營運用途。

6. 儲存、安全與保留

工作區與對話儲存在你的裝置上。Google 連線憑證透過作業系統保護加密；保護不可用時拒絕儲存。這不表示所有專案檔案或對話均加密。請保護裝置、備份及帳戶。

憑證保留至斷線或移除相關本機資料。移除連線後，對話與結果可能仍保留，直到你刪除。接收資料的服務商依自身保留設定和政策處理；我們不承諾其固定保留期限。

7. 斷線、撤銷與刪除

在 Artemis 中斷開 Google 連接器可移除本機憑證。要撤銷 Google 端權限，請在 Google 帳戶第三方連線頁移除 Artemis。本機斷線本身不會撤銷 Google 授權或刪除已存任務。

請刪除不需要的對話、匯出檔案與應用程式資料；備份另行刪除。斷線不會刪除 Google 原始郵件、Drive 檔案或 Calendar 活動，請在 Google 管理，並向模型或外掛商申請刪除其副本。

存取、更正或刪除協助請聯絡下方信箱。我們可處理你提交給支援的資訊，無法遠端刪除僅存於你裝置的檔案。請勿向支援郵件群組傳送密碼、API 金鑰、權杖或敏感郵件內容。

8. 網站及支援

本網站託管於 GitHub Pages。託管商可能處理 IP、瀏覽器等技術資訊以提供及保護網站。下載使用 GitHub 版本託管服務。

網站會依瀏覽器語言自動選擇顯示語言。手動選擇的語言儲存在瀏覽器本機儲存空間中並優先使用。你可在語言選單中變更，或清除網站儲存資料以移除已儲存的選擇。

你的電子郵件及提交資訊用於回覆支援請求。聯絡地址是 Google Groups 郵件群組，郵件經該服務處理且可能向群組成員公開。請僅提供必要資訊。

更新會在本頁發布並標示新生效日期。Google 資料用途若超出原授權，我們會在新用途實施前說明並取得同意。隱私或刪除問題請透過下方信箱聯絡 Eureka Raider。

連接，然後一起創造

從一則訊息， 到一群人的成果。

在熟悉的 IM 裡交代任務，讓電腦上的 Artemis 接手。將你的方法變成自訂智慧體，再用 Agent Team 與群組協作，把各自的專長放在一起。

IM 連接↓IM 群組協作↓自訂智慧體↓一起工作↓

IM 連接

不在電腦前， 工作也能接得上。

透過機器人私訊，把任務交給自己的 Artemis。查詢專案、處理檔案、接收結果，在原來的對話裡繼續追問，也可以處理釐清問題與本人的核准。

飛書 / Lark
飛書支援掃碼連接與串流卡片回覆；Lark 可手動設定。
Slack
透過機器人私訊連接本機工作，也可加入頻道協作。

電腦保持喚醒、Artemis 開啟且連接啟用，即可接收任務。

從訊息，到本機成果

「幫我檢查專案，整理今天的進度。」
  1. 1

    一句話，交代任務

    從你熟悉的通訊工具出發。

  2. 2

    在你的電腦上處理

    使用已授權的專案、檔案與工具。

  3. 3

    回到原來的對話

    接收進度、結果，再繼續聊。

IM 群組協作

同一個群組， 各自的能力。

在現有的 Slack 頻道、飛書或 Lark 群組裡，每位成員連接自己的機器人與 Artemis。讓任務找到合適的人，也連接對方已授權的桌面能力。

把工作交給指定成員

在群組裡 @ 對應機器人，或在 Artemis 中向群組成員分派任務。

在各自的範圍裡工作

每台電腦分別授權專案、資料夾、檔案與操作權限。

讓成果回到發起的地方

委派成果回到來源群組並提及請求者，接著完成後續工作。

自動分派需完成機器人之間的授權與連通驗證；也可由人手動 @ 下一位機器人。

自訂智慧體

把你的方法， 交給熟悉的角色。

為研究、審閱或寫作建立專屬智慧體。職責和交付要求只需定義一次，就能在適用專案裡反覆呼叫。

專屬指引
明確職責、工作方法與交付要求。
模型與思考
指定模型與思考深度，或繼承目前對話。
工具與專案
選擇可用工具，設定適用的專案範圍。
呼叫方式
在桌面用 @ 指定，或允許主智慧體依任務自動選擇。

能力，放在一起更有用

一套方法， 兩種協作方式。

自訂智慧體提供專長，Agent Team 組織本機分工，IM 群組連接不同成員的 Artemis。

讓你的專業角色，組成一支團隊。

把研究與審閱分成獨立任務，交給不同的自訂智慧體並行處理。主智慧體協調進度、整理成果，你可以在團隊面板查看每個角色的工作。

  1. 01

    拆分任務

    明確每個部分要完成什麼。

  2. 02

    呼叫專業角色

    透過 @ 任務區塊或已允許的自動呼叫，選用自訂智慧體。

  3. 03

    並行推進

    在 Agent Team 中查看分工、狀態與訊息。

  4. 04

    彙整成果

    把各個角色的結果帶回目前任務。

群組裡交代一件事，背後是一支隊伍。

為本機角色開啟自動呼叫後，群組任務到達對應的 Artemis，主智慧體便能依專案範圍選用這些角色。每位成員的電腦負責自己的部分，成果回到共同的對話。

  1. 01

    群組裡發起

    向已授權的機器人交代目標。

  2. 02

    定向分派

    把合適的工作交給對應成員的 Artemis。

  3. 03

    本機分工

    主智慧體呼叫可用的專業角色，組織本機團隊。

  4. 04

    回到群組裡

    彙整成果並回覆原請求者，繼續協作。

完整的桌面工作空間

協作之外， 完成工作的工具也在。

專案與對話查看原圖↗

讓思路，有跡可循。

把專案、對話與長期目標放在一起。隨時找回脈絡，從上次停下的地方繼續工作。

檔案與文件查看原圖↗

交付可以繼續使用的成果。

在對話旁閱讀、編輯檔案。用內建外掛處理 Word、Excel、PowerPoint 與 PDF 的基本內容。

程式與審閱查看原圖↗

交付之前，讀懂每一處修改。

在同一處查看差異、留下評論、依片段暫存。需要隔離變更時，切換到獨立工作樹。

終端機與瀏覽器查看原圖↗

把驗證，放在工作旁邊。

終端機與網頁就在對話旁。執行命令、檢查檔案、驗證結果，讓思考與操作保持連貫。

自動化查看原圖↗

讓日常工作，按時到來。

讓重複工作按計畫開始。支援一次性與週期任務，在 Artemis 開啟時執行，操作由你授權。

外掛與連接服務查看原圖↗

需要什麼，再加入什麼。

將外掛、技能、連接器與 MCP 放在一處。連接帳戶，依工作需要加入工具。

模型與用量查看原圖↗

找到適合自己的平衡。

為每段對話選模型，清楚查看 Token 用量。Ultra 提供更深入的思考與並行協作，也會消耗更多用量。

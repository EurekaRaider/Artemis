進一步了解

從開始想，到做出來。

一段可以延續的對話，加上把事情做好的工具。

01

專案與對話

讓思路，有跡可循。

儲存、搜尋、封存和分支對話。專案任務圍繞本機檔案展開，臨時對話容納獨立工作。目標模式支援持續推進較長任務，也可設定 Token 預算。

02

檔案與文件

交付可以繼續使用的成果。

閱讀和編輯檔案，預覽 Markdown，使用內建外掛建立 Word、Excel、PowerPoint 或 PDF 內容。支援基本內容處理，不保證完整保留巨集、動畫或複雜排版。

03

程式與審閱

交付之前，讀懂每一處修改。

比較上一輪、暫存區或分支的變更，加入行內評論，按區塊暫存。可以在本機目錄工作，也可主動切換到隔離的工作樹。

04

終端機與瀏覽器

把驗證，放在工作旁邊。

執行真正的終端機，開啟網頁，在對話旁檢查檔案。內建瀏覽器將網頁與桌面介面及本機檔案隔離。

05

智慧代理團隊

讓不同部分，都得到專注。

讓多個智慧代理平行處理獨立任務。為常用角色設定專屬指引、偏好模型與可用工具，用 @ 呼叫，並隨時查看進度。

06

訊息與協作

在對話發生的地方，繼續工作。

透過企業微信、飛書 / Lark 或 Slack 私訊交辦任務。在 Slack 和飛書 / Lark 群組中，各自連接的機器人可協作處理已授權工作，並將結果送回請求者。電腦與 Artemis 需要保持執行。

07

自動化

讓日常工作，按時到來。

設定單次、間隔、每日或每週任務，指定時區並查看執行紀錄。任務在 Artemis 開啟時執行；執行模式的自動化需要明確授權。

08

外掛與連接服務

需要什麼，再加入什麼。

統一管理外掛、技能、連接器和 MCP。尋找 MCP 服務、連接帳戶，或加入你信任的市集。外部市集不會預設擷取。

09

模型與用量

找到適合自己的平衡。

為每段對話選擇模型，接入相容服務，查看 Token 與快取用量。Ultra 模式為複雜任務提供更深入的思考與平行協作，同時消耗更多用量。

10

記憶與語言

少些重複，多些延續。

保留可重複使用的專案經驗和指引，按類別匯入技能與工具設定，不會默默複製憑證。支援 14 種語言、跟隨系統語言，以及阿拉伯語由右至左的介面。

外掛與連接服務

常用的能力，在同一處。

在資源中心尋找、安裝和管理工具。是否連接由你選擇，權限也始終可查。

安心，來自清楚的邊界。

了解哪些內容儲存在本機、哪些需要連接服務，以及不同模式能做什麼。

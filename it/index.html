Plan · Work · Codemode

Dal piano al lavoro completato.

    Esplora e revisiona senza modificare file. Plan non esegue Shell, MCP o estensioni eseguibili; decidi tu quando procedere.

    Modifica file ed esegui strumenti secondo la politica di approvazione scelta. Work è la modalità predefinita per le nuove attività.

    Coordina gli strumenti tramite script per lavori in più passaggi. Codemode rispetta gli stessi permessi e approvazioni di Work.

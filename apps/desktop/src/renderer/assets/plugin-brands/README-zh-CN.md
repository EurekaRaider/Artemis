# 插件品牌图标回退资源

这些 PNG 从 ArtemisPluginShop 的对应 `plugins/<name>/assets/icon.png` 原样复制，来源版本为 `ab4ff8349dc30fff3ce6648f56d7c81c2d2a1eb3`。

它们标识的服务与商店图标相同。插件 manifest 中有效的图片优先；只有图片缺失或加载失败时才使用这些内置文件。按稳定的插件名称匹配，不使用翻译后的显示标签。未知插件继续使用语义图标。

Figma 全彩图标已与[官方品牌素材](https://www.figma.com/using-the-figma-brand/)核对。品牌标识仍归各自所有者所有。

# Plugin brand fallbacks

These PNGs are copied without modification from the matching
`plugins/<name>/assets/icon.png` files in ArtemisPluginShop, revision
`ab4ff8349dc30fff3ce6648f56d7c81c2d2a1eb3`.

They identify the same services as the marketplace artwork. A plugin's valid
manifest image takes precedence; these bundled files are used only when that
image is missing or fails to load. Match the stable plugin name rather than
translated labels. Unknown plugins retain their semantic artwork.

Figma's full-color mark was cross-checked against its
[official brand assets](https://www.figma.com/using-the-figma-brand/).
Brand marks remain the property of their respective owners.

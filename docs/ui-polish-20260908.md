## 在线状态的准确含义

- 飞书、Lark、企业微信和 Slack 统一取消“未知时默认电脑在线”。没有设备在线数据时两种设备图标均不点亮，并明确提示平台未提供实时在线状态。
- 当前各渠道适配器报告的是机器人传输连接状态，没有报告个人手机、电脑的在线状态。不能把任务存在、最后一次消息或机器人连接作为个人设备在线证据。
- [Slack 官方 `users.getPresence` 文档](https://docs.slack.dev/reference/methods/users.getPresence/)对其他用户仅返回 `active`/`away`，没有逐手机/电脑状态。关闭个人 Slack 客户端不等于关闭 Artemis 的机器人 Socket Mode 连接。
- 设置页每 2 秒刷新，并在窗口重新聚焦和可见性变化时更新。刷新失败立即使已缓存渠道信号转为异常；Gateway 断连不会继续发布旧绿色状态，恢复后重新取实际连接状态。正常传播包含 Gateway 轮询和渲染轮询时间；底层网络断链检测仍受各平台心跳/请求超时影响，不宣称零延迟。
- 飞书/Lark SDK 初次握手失败后若已重新连通，清除旧的握手错误，避免显示与当前 SDK 状态不一致。

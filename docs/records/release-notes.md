# Artemis v2.0.3

## 中文

- 切换模型或思考强度时保持输入框、草稿和焦点稳定，并在选择保存完成前阻止发送，避免使用尚未保存的模型配置。
- 将模型选择菜单限制在会话区域内，避免侧边工作区面板遮挡菜单；保存选择时保留菜单的稳定布局。
- 修复从桌面启动应用时 GitHub CLI 的发现与当前 GitHub 账号登录状态检测，并为 GitHub Gist 和 Radius 分享分别提供准确的不可用提示。

## English

- Keep the composer, draft and focus stable while saving a model or reasoning effort selection, and wait for the selection to finish saving before sending a prompt.
- Keep the model picker within the conversation area so the workspace dock cannot clip it, and preserve its layout while saving a selection.
- Improve GitHub CLI discovery in desktop launches and check the active GitHub account, with separate availability messages for GitHub Gist and Radius sharing.

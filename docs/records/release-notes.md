# Artemis v1.7.2

## 中文

- 关闭设置页服务商导航行的过渡动画，避免滚动时鼠标经过条目触发绘制动画。
- 移除侧栏导航轨道的圆角，统一侧栏边缘样式。
- 同步工作区版本、MCP 客户端标识、主题版本和 README 至 1.7.2。

## English

- Disable transitions on provider navigation rows in Settings so rows passing under the pointer do not animate paints during scrolling.
- Remove sidebar rail corner rounding for consistent sidebar edges.
- Synchronize workspace versions, MCP client identities, the theme version and README at 1.7.2.

发布验收结果以本版本关联的 CI、最终产物检查和实际平台测试为准；源码变更清单不替代验收证据。
Release acceptance is established by the associated CI, final artifact checks and recorded platform tests, not by these change notes alone.

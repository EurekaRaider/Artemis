# Artemis v2.0.13

## 中文

- 浏览带有图片、视频或 HTML 预览的长对话时，惯性滚动减速阶段的卡顿有所减少。
- 滚回刚看过的消息时，聊天记录会复用已加载的图片和已渲染的公式、图表，减少重复加载。

## English

- Reduce stutter as momentum scrolling slows in long conversations with image, video, or HTML previews.
- Reuse loaded images and rendered equations and diagrams when you scroll back to a message.

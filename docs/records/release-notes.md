# Artemis v1.6.14

## 中文

- **时间线技能图标**：Computer Use 技能标签使用与资源中心一致的显示器图标，不再错误显示四宫格。
- **插件图标回退**：保留 Gmail 等插件提供的图片；图片缺失或加载失败时，使用内置品牌图标或语义图标。保持标签原有尺寸。

发布目标为 macOS arm64（签名、公证 DMG/ZIP）与 Windows x64（未签名 ZIP），沿用已发布 Office Runtime。Intel macOS 保留本地打包支持，不在本次 CD 发布范围内。

## English

- **Timeline skill icons**: Computer Use skill labels now use the same monitor artwork as the resource center instead of the generic grid icon.
- **Plugin icon fallback**: plugin-provided images, including Gmail artwork, remain preferred. Missing or failed images fall back to bundled brand or semantic artwork while preserving label dimensions.

Release targets are macOS arm64 (signed, notarized DMG/ZIP) and Windows x64 (unsigned ZIP), reusing published Office runtimes. Intel macOS remains a local packaging target and is not included in this CD release.

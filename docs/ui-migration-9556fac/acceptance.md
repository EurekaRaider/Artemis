# 9556fac UI 迁移验收记录

本轮实现已落地，工程门禁和已覆盖的 macOS arm64 原生场景通过。**完整视觉验收仍未关闭**：原型页面访问受策略限制，本轮没有原型运行截图；不能用生产前后对照或历史 v69 报告替代原型一致性验收。

## 实现范围

- 固定 `9556fac` 原型的 84 个文件，保留旧基线，生产代码不加载原型 HTML 或模拟脚本。
- 主题迁移到最新黑白主色、品牌蓝、成功绿、目标金色及上下文/用量色阶，覆盖四个主题/对比度模式。20 个新增可选令牌提供兼容回退；旧主题的新表面继承自己的已验证颜色。
- 合并活动栏和项目侧栏，展开默认 260px、窄窗 240px，48px 收起栏与悬停浮层互斥，支持点击固定、立即收起、键盘焦点恢复。1060px 以下默认收起，保留手动固定和持久化宽度。
- 目标入口迁入输入区，保留暂停、恢复、编辑、删除及预算状态；计划浮条保持独立。增加模型筛选、真实上下文分类展示及长标题滚动。
- Dock、环境浮层、设置和辅助页面使用迁移后的共享主题及组件。设置窄窗导航与六类入口保持可访问；生产组件和操作链路继续复用。
- `main.ts` 的改动仅用于将旧烟测的活动栏位置索引改为稳定页面选择器。业务协议、IPC 定义、Pi 循环及权限规则没有更改。

## 体积变化

同依赖版本、隔离源码构建测得生产 CSS 从 **319175** 增至 **337772** 字节（+18597，5.83%）。新增导航结构、输入区样式和兼容令牌构成新的设计体积；CSS 门限单独调整为 342000，其他性能门限不变。此记录不等于新的启动性能基线。

用户最终澄清：#226 来自其他用户的 Issue，报告未说明当时是否存在人工输入。因此“完全没有人工输入”不是本次结论的证据；有输入与无输入两种情况都需要区分。

任务授权只属于当前父任务及可信内置 Computer Use。它不扩大用户的业务请求，`computer_act` 保留高风险下限和 `explicitUserRequest` 要求。旧持久许可不会自动升级；本轮、任务、持久访问分别显示。Stop 保留任务许可，恢复后重新打开并观察；撤销、离开 Execute、归档、删除、插件断开或禁用、退出应用清除任务许可。每次执行前重新核对当前轮次、许可 ID 和真实控制租约，异步完整性校验期间撤销或切换模式也不能继续签发票据。

图标解析优先使用轮次、父代理、调用 ID 对应的来源记录，再使用精确登记的工具名；不猜测品牌前缀。索引仅随插件及 MCP 注册表变化重建。没有事件迁移、外部图标下载或额外模型请求。

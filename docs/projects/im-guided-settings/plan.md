## 2. 阶段一：生产侧先行项

### PR-S1 连接状态枚举统一
- **背景**：提案 §2.2 要求区分「未配置→保存中→已保存/连接中→已连接」，现产各处状态散乱（review §2.1-②）。
- **动作**：连接状态收敛为单一枚举 `unconfigured | saving | saved | connecting | connected | partial_error`，UI 与 store 同源。
- **验收标准**：
  1. 渲染层不再出现枚举之外的连接状态字符串（grep 可证）；
  2. 保存凭据与连接建立是两个可观察状态（先 `saved/connecting` 后 `connected`），保存成功而连接未建立时 UI 不显示「已连接」；
  3. 现有 desktop 测试全绿，新增至少一条枚举流转断言。

### PR-S2 「保存并启用」两阶段入口与部分成功返回
- **背景**：现产保存授权（`ImSettingsPanel.tsx:1998-2003`）与顶部开关启用（`:690-714`）是两个非原子操作（review §2.1-⑥）。
- **动作**：提供组合入口 API：先保存授权，成功后再启用；启用失败返回可区分的部分成功状态。
- **验收标准**：
  1. 保存失败 ⇒ 不发起启用，错误归授权表单；
  2. 保存成功、启用失败 ⇒ 返回结构可区分两阶段结果，UI 能呈现「授权已保存，连接未启用」且仅提供「重试启用」；
  3. 两阶段各自可重试，重试不重复产生副作用（无重复 grant）。

### PR-S3 空 scope 语义确认（D3 前提）
- **背景**：D3 决议首次默认「可读整个项目、不可写任何文件」，需生产确认无 readPaths 的 grant 语义（`ImDataPermissions.tsx` / `im-service.ts` 校验）。
- **动作**：二选一并记录决议：a) 空 scope = 项目根可读（补协议/服务端定义）；b) 必须显式选择（原型改为「首步引导勾项目根一个节点」）。
- **验收标准**：
  1. 决议写入本文件附录或 im-security README；
  2. 按决议调整校验：方案 a 则空 readPaths+plan 模式可保存；方案 b 则空 scope 保存被拒且有明确错误文案；
  3. writePaths ⊆ readPaths 校验不变（回归断言）。

### PR-S4 测试任务关联逻辑立项决议（D4 落档）
- **动作**：记录决议——本期诚实版为 V1；自动验收（消息→任务→完成→回执四段关联 + 防历史任务冒充）单独立项排期。
- **验收标准**：决议出现在 im-gateway README 或本目录文档；`ImSetupGuide` 第 6 步 done 硬编码 false 的现状在文档中如实标注（不伪装自动验收）。

### PR-S5 im-gateway README 过时点修订

- **动作**：按当前实现修订三处。
- **验收标准**：三处修订后与 `ImSettingsPanel.tsx`/`ImSpaceBuilder.tsx` 现状一致（字段、按钮文案、表单工作流）；文档内不再出现「保存并启用连接」「填写 Tenant Key」等已过时表述。

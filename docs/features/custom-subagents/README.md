# 自定义子智能体

自定义子智能体是可复用的角色定义，可关联全部或选定项目，通过结构化 `@` 手动调用，或允许模型从当前项目的有效目录中选择。定义、项目关联、权限快照、手动调用与自动路由已经实现；Pi 仍是唯一 Agent 循环。

## 配置与调用

在设置的智能体配置中管理名称、描述、专用指令、项目范围、模型、思考策略、工具白名单及自动调用开关。指定项目的定义只对关联项目生效；项目的 Local checkout 与 worktree 使用同一项目关联。

- 手动调用：在线程空闲时，从输入框的 `@` 菜单选择定义，再发送任务。引用保存定义 ID 和 revision，普通文本中的 `@名称` 不构成调用授权。
- 自动调用：仅把当前项目中启用且允许自动调用的定义加入目录。精确角色名匹配用于纠偏，触发词只给出候选，不强制认定任务适合该角色；歧义不得按列表顺序偷偷选择。
- 自动目录最多 20 个定义、合计 4096 字符。超出预算时停用自动目录及名称纠偏，并在设置页提示；手动调用保留。
- 实例展示定义名称、版本、模型和调用来源。路由审计分别记录 `invocationSource` 和 `selectionBasis`。

## 权限、幂等与生命周期

实例的有效能力是父任务权限、运行模式、定义工具策略及实际可用工具的交集。Plan/Review 的只读限制始终生效；定义不能授予父任务没有的写入、Shell、MCP 或可执行扩展能力。工具白名单按具体工具 ID 检查，空白名单不提供业务工具。

接受调用时冻结定义版本、指令、完整工具策略、模型与思考配置。固定模型不存在时，在创建实例及扣减预算前拒绝。之后扩大定义权限不会扩张已接受实例；缩小工具权限、停用、删除或移出项目会阻止后续不再允许的调用，并取消尚未启动的实例。重试重新检查当前有效权限。

调用以线程和 invocation ID 去重：相同 ID、相同内容复用已有调用，内容不同则拒绝。去重先于创建初始回合事件，避免冲突调用留下假运行状态。失效定义返回明确错误，不静默退化为自由角色。

恢复检查点不保存完整定义或专用指令。进程重启后的恢复回合不自动委派自定义实例；用户发起新回合后重新读取有效定义。

## 限制与回退

- 结构化 `@` 仅在发送新轮时生效；运行中跟随消息携带自定义引用会被拒绝，排队消息携带引用尚未交付。
- 触发词与确定性路由测试不等于实时模型的语义选人准确率；固定模型和配置下的对比实测仍待补。
- 仓库共享定义不在当前交付范围，需要另行确定信任来源与优先级。
- 静态 UI 原型没有对应完整子智能体页面，不能替代生产 Renderer 交互验证。
- 关闭定义的自动调用开关或清空自动集合，可退回纯手动调用。
- 存储采用增量迁移；旧二进制可能不认识新的事件载荷。回退应恢复升级前的兼容备份，不应让旧版本直接打开升级后的数据库。

# Artemis UI 视觉方向原型 · 方向 A「Apple-inspired Artemis」

当前组件库实现位于 [`ui/`](ui/README.md)。两个 HTML 入口共用 `ui/index.css`、`ui/index.js` 和业务组合模块；页面布局、展示脚本和演示数据分别放在 `showcase/`、`workspace/` 中。`component-tokens.css` 保留为兼容入口。

本轮已接入共享控件、菜单、标签、弹窗、分栏、任务计划和目标编辑器。70 张卡的具体迁移状态见 [`ui/migration-map.json`](ui/migration-map.json)，未将剩余业务演示或原型检查计为正式 React/Electron 迁移完成。

新增验证：`node docs/ui-prototype/tools/library-check.mjs`（在仓库根运行）。完整使用方式、离线导出与 API 见 [组件库文档](ui/README.md)。打开或分发原型时需保留整个目录；也可用 `tools/inline-assets.cjs` 导出单文件。


页面原型已按当前 Artemis 主界面和子面板重新编排：9 类 Dock 面板、6 个独立设置页、环境分组及资源分类均可从对应入口访问。详见 [编排与自检记录](apple-inspired-ui-validation.md)。默认方案 1、浅色、标准模式。

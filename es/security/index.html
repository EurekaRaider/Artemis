Privacidad y control

Tu espacio. Límites claros.

Conoce dónde vive tu trabajo y qué permites. El almacenamiento local, los modelos en línea y los servicios tienen funciones distintas.

Planificar · Ejecutar · Revisar

Espacio para pensar antes de actuar.

Planificar y Revisar bloquean cambios antes de ejecutarlos. Ejecutar aplica la política de aprobación elegida. Los comandos aprobados y el terminal usan los permisos de tu usuario del escritorio.

PlanificarRevisarSolo lecturaEjecutar
01

Contexto local

En tu equipo, con salidas claras.

Los proyectos y las conversaciones se guardan localmente. Las instrucciones, los archivos y los resultados pertinentes pueden enviarse al modelo o servicio elegido.

02

Credenciales

Protección del sistema operativo.

Las claves API y credenciales se cifran con el sistema operativo. Si la protección no está disponible, no se guardan secretos. Esto no cifra todos los archivos o conversaciones.

03

Herramientas y extensiones

Cada herramienta, sus permisos.

Los servidores MCP locales usan aislamiento nativo por defecto, con ajustes de red y compatibilidad individuales. Las extensiones ejecutables requieren confianza explícita. El acceso local completo solo afecta a extensiones.

04

Permisos de mensajería

Comparte dentro del alcance elegido.

Autoriza proyectos, carpetas o archivos para cada destinatario. Escritura, comandos y red tienen permisos separados. Estar en un grupo no concede acceso a tu equipo.

Conecta con conocimiento.

Consulta cómo funcionan las cuentas, el procesamiento por modelos, la conservación y la eliminación antes de usar información sensible.

概要機能プライバシーと管理ダウンロード

発効日：2026 年 9 月 19 日 · 運営者：Eureka Raider

プライバシーポリシー

作業空間は端末に保存されます。アカウントやオンラインモデルを使う場合は、選んだサービスも関わります。その境界をご説明します。

1. 対象と運営者

Eureka Raider はデスクトップ AI 作業空間 Artemis と本サイトを提供します。本方針は Artemis、Google 連携、サポートでの情報の取り扱いに適用されます。第三者サービスには独自の方針も適用されます。

2. アクセスする情報

提供または許可された指示、ファイル、プロジェクト内容、ツール結果、会話履歴を処理します。選んだサービスを使うにはモデル設定と接続アカウントの認証情報も必要です。

Google 接続ではアカウント識別子、メールアドレス、プロフィールを取得してアカウントを識別します。コネクタと許可に応じ、Gmail の本文、ヘッダー、宛先、添付、下書き、ラベル、Google Drive の文書・表・スライドを含む内容とメタデータ、Google Calendar のカレンダー、予定、参加者、空き時間にアクセスします。要求権限は Google の同意画面に表示されます。

3. Google 権限の目的

Gmail は依頼された検索、閲覧、下書き、送信、整理に、Drive はファイルの検索、閲覧、作成、更新に、Calendar は予定の確認、作成、更新、削除に使います。操作は利用可能なツールとあなたの指示によります。

Google 接続は任意です。データは依頼した連携機能のために使い、広告、広告用プロファイリング、信用判断には使用せず、販売もしません。

4. モデルとその他の受領者

Google のメール、ファイル、予定、ツール結果の関連部分は、タスクを行うため設定した AI 提供者への会話に含まれる場合があります。ローカル優先は端末内だけでの処理を意味しません。機密情報には適切な提供者と保存設定を選んでください。

接続ツールやプラグインは許可した操作に必要なデータを受け取ります。メール送信、共有、投稿では指定した相手にも内容を開示します。端末は Google や設定サービスと通信し、本サイトは Google 認証トークンを受け取りません。

Google データの転送は、同意に基づく依頼機能の提供、必要な安全対策、法的義務、または事前の明示的同意を得た運営主体の譲渡に限られます。

5. Google API と制限付き利用

Google API から受け取る情報の利用と転送は、Google API Services User Data Policy と Limited Use 要件に従います。

Google ユーザーデータを汎用 AI や機械学習モデルの開発、改善、学習に利用しません。依頼への回答のためのモデル処理と学習は別です。この制限を守る提供者と設定のみを使用してください。

Google データを日常的に人が読むことはありません。人によるアクセスは特定データへの明示的同意、必要な安全調査、法的義務、または Google 方針が認める集計された内部運営に限られます。

6. 保存と安全性

作業空間と会話は端末に保存します。Google の認証情報は OS の保護で暗号化し、保護が使えなければ保存しません。すべてのファイルや会話を暗号化する意味ではありません。端末、バックアップ、アカウントを保護してください。

認証情報は切断または関連ローカルデータの削除まで残ります。会話や成果物は接続削除後も、削除するまで残る場合があります。提供者へ渡ったデータにはその保存方針が適用され、当方は保存期間を保証しません。

7. 切断、取消し、削除

Artemis で Google コネクタを切断すると保存済みのローカル認証情報を除去できます。Google 側の権限は Google アカウントの第三者接続から Artemis を削除してください。ローカル切断自体は Google の許可取消しや過去のタスク削除にはなりません。

不要な会話、書き出したファイル、アプリデータと、別途バックアップを削除してください。切断は元の Gmail、Drive、Calendar の内容を削除しません。Google 上で管理し、提供者が持つコピーの削除はその提供者に依頼してください。

アクセス、訂正、削除の支援は下記へご連絡ください。当方が扱えるのは支援のため提出された情報で、端末だけにあるファイルを遠隔削除できません。パスワード、API キー、トークン、機密メールを支援メーリングリストに送らないでください。

8. サイトとサポート

本サイトは GitHub Pages で配信されます。ホストは配信と保護のため IP やブラウザ等の技術情報を扱う場合があります。ダウンロードは GitHub のリリース配信を利用します。

サイトはブラウザーの言語設定に合わせて表示言語を選びます。手動で選んだ言語はブラウザーのローカルストレージに保存され、優先されます。言語メニューで変更するか、サイトの保存データを削除して選択を解除できます。

メールアドレスと提出情報はお問い合わせへの回答に使用します。連絡先は Google Groups のメーリングリストで、そのサービスで処理され、グループメンバーが閲覧する場合があります。必要最小限の情報だけお送りください。

9. 更新と連絡先

変更は新しい発効日とともに掲載します。Google データの用途が従来の許可を超える場合は、事前に説明して同意を得ます。プライバシーや削除については下記の Eureka Raider 宛てにご連絡ください。

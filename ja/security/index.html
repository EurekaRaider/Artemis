プライバシーと管理

あなたの作業空間。明確な境界。

仕事の保存先と、許可した範囲を知る。ローカル保存、オンラインモデル、接続ツールにはそれぞれの役割があります。

計画 · 実行 · レビュー

動き出す前に、考える余白を。

計画とレビューは実行前にファイル変更を防ぎます。実行は選択した承認方針に従います。承認済みシェルコマンドとターミナルは、デスクトップユーザーの権限で動きます。

計画レビュー読み取り専用実行
01

ローカルの文脈

手元に保存し、送信先も明確に。

プロジェクトと会話履歴はローカルに保存。関連する指示、ファイル、ツール結果は、選んだモデルや接続サービスに送られる場合があります。

02

認証情報

OS の保護機能を利用。

API キーや接続の認証情報は OS で暗号化。保護が使えない場合は保存しません。すべてのファイルや会話が暗号化されるわけではありません。

03

ツールと拡張

権限はツールごとに。

ローカル MCP は標準でネイティブ隔離を使い、ネットワークと互換性を個別設定できます。実行可能な拡張には明示的な信頼が必要。完全なローカルアクセス設定は拡張だけに適用されます。

04

IM の許可

選んだ範囲で共有する。

相手ごとにプロジェクト、フォルダ、ファイルを許可。書き込み、コマンド、ネットワークは別々に管理します。グループ参加だけではコンピュータへのアクセスを許可しません。

理解してから、つなぐ。

機密情報を扱う前に、アカウント接続、モデル処理、保存期間、削除方法をご確認ください。

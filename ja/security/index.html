プライバシーと管理

あなたの作業空間。明確な境界。

仕事の保存先と、許可した範囲を知る。ローカル保存、オンラインモデル、接続ツールにはそれぞれの役割があります。

Plan · Work · Codemode

動き出す前に、考える余白を。

ファイルを変更せずに調査・レビュー。Plan では Shell、MCP、実行可能な拡張機能を使わず、実行の開始はあなたが決めます。 選択した承認方針に従ってファイルを編集し、ツールを実行。Work は新しいタスクの既定モードです。 スクリプトでツールを連携し、複数の手順を進めます。Codemode の権限と承認は Work と同じです。

ローカルの文脈

手元に保存し、送信先も明確に。

プロジェクトと会話履歴はローカルに保存。関連する指示、ファイル、ツール結果は、選んだモデルや接続サービスに送られる場合があります。

認証情報

OS の保護機能を利用。

API キーや接続の認証情報は OS で暗号化。保護が使えない場合は保存しません。すべてのファイルや会話が暗号化されるわけではありません。

ツールと拡張

権限はツールごとに。

ローカル MCP は標準でネイティブ隔離を使い、ネットワークと互換性を個別設定できます。実行可能な拡張には明示的な信頼が必要。完全なローカルアクセス設定は拡張だけに適用されます。 承認済みの Shell コマンドと統合ターミナルはデスクトップユーザー権限で動作します。ローカル MCP は既定で隔離され、理由と承認のある一度限りの権限昇格は保存済み設定を変えません。

IM の許可

選んだ範囲で共有する。

相手ごとにプロジェクト、フォルダ、ファイルを許可。書き込み、コマンド、ネットワークは別々に管理します。グループ参加だけではコンピュータへのアクセスを許可しません。

理解してから、つなぐ。

機密情報を扱う前に、アカウント接続、モデル処理、保存期間、削除方法をご確認ください。

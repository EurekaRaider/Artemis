Plan · Work · Codemode

計画から、仕事の完成へ。

まず計画し、直接作業し、Codemode でツールを連携。ファイル、結果、判断を一つのワークスペースに。

Plan

ファイルを変更せずに調査・レビュー。Plan では Shell、MCP、実行可能な拡張機能を使わず、実行の開始はあなたが決めます。

Work

選択した承認方針に従ってファイルを編集し、ツールを実行。Work は新しいタスクの既定モードです。

Codemode

スクリプトでツールを連携し、複数の手順を進めます。Codemode の権限と承認は Work と同じです。

会話の中で、結果を確認。

画像、アニメーション SVG、音声、動画、Mermaid、LaTeX を表示。ローカル HTML は隔離環境で動作し、Office と PDF はカードからサイドビューアーで開きます。

あなたらしいワークスペース。

スキンプラグインをプレビューして適用、または既定に戻せます。対応スキンでは明暗の壁紙、無音動画、フォント、アイコン、動きを抑える設定を利用できます。

いつもの手順を、必要なときに。

設定でコマンド Hooks を確認して明示的に信頼します。Work と Codemode で動作し、Plan ではスキップ。プラグイン、Skills、MCP はリソースセンターで管理します。

インタラクティブなプラグイン

隔離されたパネルとツールを追加できます。Design プラグインがインストールされ利用可能な場合、文書作成、履歴、取り消し、復元を利用できます。プロジェクトのファイルは明示的なインポートが必要です。

Office · DOCX / XLSX / PPTX / CSV

会話の隣で、文書を仕上げる。

Office ワークベンチで Word、Excel、PowerPoint をプレビュー、編集、注釈付け。手動編集はローカルで処理され、自動保存と元に戻す・やり直しに対応します。

Office のプレビューには追加の Office コンポーネントのインストールと有効化が必要です。基本の文書プラグインは別途利用できます。

  1. Word と PowerPoint

    一意に特定できる DOCX の段落と PPTX オブジェクトの文字をその場で編集。ズームやスライドのサムネイルで確認できます。

  2. Excel と CSV

    各シートの A1:Z50 内で XLSX の値と数式を編集し、グリッドと印刷プレビューを切り替えます。CSV はセルとソースを編集でき、競合確認後に UTF-8 の原本へ保存します。

  3. 場所を選んで、変更を伝える

    文字の対象、セル、ページ領域を選んで注釈を追加。選択範囲と文書バージョンが入力欄に入り、確認して送信できます。

Documents、Presentations、Spreadsheets のいずれかで Office のアップグレードを選び、共通のオプションコンポーネントをオンラインでインストールするか、.artemis-office ファイルを読み込みます。macOS の Apple シリコンと Windows x64 に対応。編集と保存には Work / Codemode モードが必要です。

Office ファイルは作業用コピーに保存し、原本を保持します。外部変更との競合時は上書きを防止。編集対象は対応する文字とセルで、Office の全レイアウト機能には対応せず、複雑な書式には差異が生じる場合があります。

Office を、画面で見る。

画面はサンプルデータを使用しており、現在のリリースと異なる場合があります。

Computer Use · Windows 11 / macOS 14+

ひと言の依頼を、画面上の操作へ。

Artemis は内蔵ブラウザーでフォームへの入力、操作項目のクリック、Web サイトの閲覧を行い、Windows と Mac のネイティブアプリも操作できます。

ブラウザでこの申込フォームに入力し、送信前に確認させて。

Windows 11 x64 と Apple シリコン搭載の macOS 14 以降に対応。macOS のネイティブアプリ操作にはアクセシビリティと画面収録の許可が必要です。

ブラウザーでの実際の操作 · ネイティブアプリのライブ PiP

macOS で録画し、切り抜きと速度調整を行っています。デモの画面は英語です。

  1. 数ステップで準備完了

    リソースセンターの同梱プラグインから Computer Use をインストール。Work / Codemode で画像対応モデルを選び、タスクを伝えるだけ。追加のモデルキーは不要です。

  2. 操作の主導権はあなたに

    アプリごとにアクセスを許可し、いつでも停止できます。前面での操作には別途許可が必要で、保存したアプリの許可も取り消せます。

IM 接続

デスクを離れても、 仕事はつながる。

自分のボットへのメッセージから、プロジェクトの確認やファイルの作業を依頼。結果を受け取り、同じ会話で質問を続けられます。確認事項への回答や本人の承認にも対応します。

Feishu / Lark
Feishu は QR 接続とストリーミングカード返信に対応。Lark は手動で設定できます。
Slack
ボットとの個別メッセージでローカル作業を依頼し、チャンネルでも連携できます。

受信には、パソコンがスリープしておらず、Artemis と接続が有効である必要があります。

メッセージから、手元の作業へ

「プロジェクトを確認して、今日の進捗をまとめて。」

  1. メッセージで依頼

    使い慣れたツールから始めます。

  2. 自分のパソコンで作業

    許可したプロジェクト、ファイル、ツールを使います。

  3. 同じ会話に戻る

    進捗と結果を受け取り、続けて相談できます。

IM グループ連携

ひとつの会話に、 それぞれの得意を。

既存の Slack チャンネルや Feishu / Lark グループで、各メンバーが自分のボットと Artemis を接続。適した人に仕事を渡し、その人が許可したデスクトップの機能を活かせます。

相手を指定して依頼

グループでボットを @ 指定するか、Artemis からメンバーにタスクを割り当てます。

それぞれの範囲で作業

プロジェクト、フォルダー、ファイル、操作の権限はパソコンごとに設定します。

依頼元へ結果を返す

委任した結果は元のグループに戻り、依頼者にメンションして次の作業へつなぎます。

自動委任にはボット間の許可と往復通信の検証が必要です。人が次のボットを手動で @ 指定することもできます。

カスタムエージェント

あなたの進め方を、 頼れる役割に。

調査、レビュー、執筆のための専用エージェントを作成。役割と成果物を一度定義すれば、選んだプロジェクトで繰り返し呼び出せます。

専用の指示
責任、作業方法、期待する成果物を定めます。
モデルと思考
モデルと思考レベルを指定するか、会話の設定を引き継ぎます。
ツールとプロジェクト
使えるツールと、役割を適用するプロジェクトを選びます。
呼び出し方
デスクトップで @ 指定するか、適したタスクで主エージェントが自動選択できるようにします。

たとえば、こんな役割分担

@

調査担当

資料と出典を整理し、根拠のある結論をまとめます。

@

レビュー担当

論拠や見落としを確認し、具体的な改善案を示します。

ひとつの役割を、さまざまなタスクで活かせます。

組み合わせて広がる力

ひとつの方法。 ふたつの連携。

カスタムエージェントが専門性を担い、Agent Team がパソコン内の分担を整理。IM グループが、各メンバーの Artemis をつなぎます。

専門の役割を、ひとつのチームに。

調査とレビューを独立したタスクに分け、カスタムエージェントが並行して進めます。主エージェントが調整と結果の整理を担当。各役割の進捗はチームパネルで確認できます。

  1. 作業を分ける

    各部分で必要な成果を明確にします。

  2. 専門役を呼ぶ

    @ タスクブロック、または許可済みの自動呼び出しを使います。

  3. 並行して進める

    Agent Team で担当、状態、メッセージを確認します。

  4. 成果をまとめる

    各役割の結果を現在のタスクに戻します。

グループのひとつの依頼を、チームで。

ローカルの役割に自動呼び出しを許可すると、グループから届いたタスクに主エージェントが適用範囲内の役割を選べます。各パソコンが自分の担当を進め、結果を共通の会話へ返します。

  1. グループで依頼

    許可したボットに目標を伝えます。

  2. メンバーへ割り当て

    適した作業をその人の Artemis に渡します。

  3. 手元で分担

    主エージェントが使える専門役を呼び、チームを組みます。

  4. グループへ返信

    成果をまとめて依頼者に返し、連携を続けます。

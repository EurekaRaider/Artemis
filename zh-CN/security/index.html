隐私与掌控

你的工作区，清楚的边界。

知道工作保存在哪里，也知道自己授权了什么。本地存储、在线模型与连接工具，各有各的作用。

规划 · 执行 · 审阅

先留一点思考的空间。

规划与审阅会在执行前阻止文件修改。执行模式按所选审批策略开放操作；获批的 Shell 命令和你打开的终端，使用当前桌面用户权限。

规划审阅只读边界执行
01

本地上下文

保存在设备上，也说明何时会发送。

项目与对话记录保存在本地。相关提示词、文件和工具结果仍可能发送至你选择的模型或已连接服务。

02

凭据

交给操作系统保护。

API 密钥与连接凭据使用操作系统加密。保护不可用时拒绝保存秘密信息；这不代表所有文件与对话均被加密。

03

工具与扩展

每一种工具，有自己的权限。

本地 MCP 服务默认使用原生隔离，可单独设置网络和兼容模式。可执行扩展需要明确信任；完全本地访问设置仅影响扩展。

04

IM 授权

在选定的范围里，共享工作。

为不同接收方授权项目、文件夹或文件。写入、命令与网络权限分别管理；加入群组本身，不会获得你的电脑访问权。

了解之后，再连接。

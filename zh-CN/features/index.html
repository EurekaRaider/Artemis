完整的桌面工作空间

协作之外， 把事情做完的工具也在。

项目与对话

让思路，有迹可循。

保存、搜索、归档和分支对话。项目任务围绕本地文件展开，临时会话容纳独立工作。目标模式支持持续推进较长任务，也可设置 Token 预算。

文件与文档

交付可以继续使用的结果。

阅读和编辑文件，预览 Markdown，使用内置插件创建 Word、Excel、PowerPoint 或 PDF 内容。支持基础内容处理，不保证完整保留宏、动画或复杂排版。

代码与审阅

交付之前，读懂每一处修改。

比较上一轮、暂存区或分支的变更，添加行内评论，按片段暂存。可以在本地目录工作，也可主动切换到隔离的工作树。

终端与浏览器

把验证，放在工作旁边。

运行真实终端，打开网页，在对话旁检查文件。内置浏览器将网页内容与桌面接口及本地文件隔离。

自动化

让日常工作，按时到来。

设置一次性、间隔、每日或每周任务，指定时区并查看运行记录。任务在 Artemis 开启时运行；执行模式的自动化需要明确授权。

插件与连接服务

需要什么，再添加什么。

统一管理插件、技能、连接器和 MCP。发现 MCP 服务，连接账户，或添加你信任的市场。外部市场不会默认拉取。

模型与用量

找到适合自己的平衡。

为每段对话选择模型，接入兼容服务，查看 Token 与缓存用量。Ultra 模式为复杂任务提供更深的思考与并行协作，同时消耗更多用量。

记忆与语言

少些重复，多些延续。

保留可复用的项目经验和指引，按类别导入技能与工具配置，不会静默复制凭据。支持 14 种语言、跟随系统语言，以及阿拉伯语从右向左的界面。

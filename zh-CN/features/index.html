完整的工作界面

任务所需的一切，都不会中途丢失。

Artemis 把持久任务上下文、执行工具、审查与扩展能力组合在一个本地桌面工作空间中。

01

Persistent tasks

工作不会因提示词结束而消失。

项目任务和临时任务各自保留事件历史与工作上下文，回来后可以继续推进，而不必重新拼装现场。

  • 项目作用域的本地检出目录
  • 带版本的持久事件
  • 无需长期保留时使用临时任务
02

Plan · Execute · Review

模式直接定义能力边界。

Plan 和 Review 会在执行器或文件系统调用发生前拒绝写入；只有 Execute 会提供可执行工具。

  • Plan 与 Review 保持只读
  • 执行界面只在 Execute 中出现
  • 编辑器中始终显示当前模式
03

Git-native Review

在工作发生的地方审查修改。

在同一任务环境中检查仓库变更，并进入提交或推送流程，让实现与证据保持在一起。

  • 感知工作区的 diff
  • 分支目标控制
  • 发布动作前确认
04

Terminal 与 Browser

使用真实工作本就依赖的工具。

集成终端以当前桌面用户运行且不会自动提权；内置浏览器支持 Web，但不会获得 Node、preload API 或本地文件访问能力。

  • 用户主动打开的本地终端
  • 支持 HTTP 与 HTTPS 的浏览器
  • Renderer 不接触 Electron main 或 Node API
05

Plugins · Skills · MCP

扩展能力，同时保留来源可见性。

在专门的资源中心发现、检查和管理集成，并根据能力类型应用对应的信任和沙盒控制。

  • 内置与本地 Plugins
  • 可复用工作流 Skills
  • 按服务配置 MCP 控制
06

Automations 与 Memory

持续有用的工作，同时约束记忆。

周期任务可以有意地再次唤醒；经验记忆保持项目优先、经过验证，并低于当前请求和系统策略。

  • 周期任务工作流
  • 项目优先的经验记忆
  • 记忆中不保存密钥或临时任务状态

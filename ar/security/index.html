الخصوصية والتحكم

مساحتك. حدود واضحة.

اعرف أين يُحفظ عملك وما الذي تسمح به. لكل من التخزين المحلي والنماذج المتصلة والأدوات دور مختلف.

Plan · Work · Codemode

مساحة للتفكير قبل الفعل.

ابحث وراجع دون تغيير الملفات. لا يشغّل Plan أدوات Shell أو MCP أو الإضافات التنفيذية؛ أنت تختار متى تبدأ التنفيذ. حرّر الملفات وشغّل الأدوات وفق سياسة الموافقة المختارة. Work هو الوضع الافتراضي للمهام الجديدة. نسّق الأدوات عبر نصوص برمجية للأعمال متعددة الخطوات. يتبع Codemode نفس الصلاحيات والموافقات الخاصة بوضع Work.

السياق المحلي

على جهازك، مع مسار نقل واضح.

تُحفظ المشاريع والمحادثات محليًا. قد تُرسل المطالبات والملفات ونتائج الأدوات ذات الصلة إلى النموذج أو الخدمة التي تختارها.

بيانات الاعتماد

يحميها نظام التشغيل.

تُشفّر مفاتيح API وبيانات الاتصال بوسائل النظام. إن لم تتوفر الحماية، تُرفض كتابة الأسرار. هذا لا يعني تشفير جميع الملفات والمحادثات.

الأدوات والامتدادات

لكل أداة أذوناتها.

تستخدم خوادم MCP المحلية العزل الأصلي افتراضيًا مع إعدادات شبكة وتوافق منفصلة. تتطلب الامتدادات التنفيذية ثقة صريحة. الوصول المحلي الكامل يخص الامتدادات فقط. تستخدم أوامر Shell المعتمدة والطرفية صلاحيات مستخدم سطح المكتب. يُعزل MCP المحلي افتراضياً؛ ولا يغيّر رفع الصلاحيات المبرّر والمعتمد لاستدعاء واحد الإعدادات المحفوظة.

أذونات الرسائل

شارك ضمن النطاق الذي تختاره.

صرّح بمشاريع أو مجلدات أو ملفات لكل جمهور. أذونات الكتابة والأوامر والشبكة مستقلة. العضوية في مجموعة وحدها لا تمنح وصولًا إلى جهازك.

افهم ثم اتصل.

اقرأ عن الحسابات ومعالجة النماذج والاحتفاظ والحذف قبل استخدام معلومات حساسة.

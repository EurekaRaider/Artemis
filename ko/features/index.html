연결하고, 함께 만드세요

메시지 하나에서, 함께 만든 결과까지.

익숙한 IM에서 일을 맡기면 컴퓨터의 Artemis가 이어받습니다. 나만의 방식을 사용자 지정 에이전트로 만들고, Agent Team과 그룹 협업으로 각자의 강점을 모으세요.

IM 연결

책상 밖에서도, 작업은 이어집니다.

자신의 봇과 직접 대화하며 프로젝트 확인과 파일 작업을 맡기고 결과를 받으세요. 같은 대화에서 질문을 이어가고, 확인 요청이나 본인 승인도 처리할 수 있습니다.

Feishu / Lark
Feishu는 QR 연결과 스트리밍 카드 답장을 지원합니다. Lark는 수동으로 설정할 수 있습니다.
Slack
봇과의 개인 메시지로 로컬 작업을 연결하고 채널에서 협업합니다.

작업을 받으려면 컴퓨터가 깨어 있고 Artemis와 연결이 활성화되어 있어야 합니다.

메시지에서 로컬 작업으로

“프로젝트를 확인하고 오늘의 진행 상황을 정리해 줘.”
  1. 1

    메시지로 시작

    평소 사용하는 메시지 도구에서 요청합니다.

  2. 2

    내 컴퓨터에서 처리

    허용한 프로젝트, 파일, 도구를 사용합니다.

  3. 3

    원래 대화로 돌아오기

    진행 상황과 결과를 받고 다음 질문을 이어갑니다.

Artemis

IM 그룹 협업

같은 대화에, 각자의 강점을.

기존 Slack 채널이나 Feishu / Lark 그룹에서 각자가 자신의 봇과 Artemis를 연결합니다. 알맞은 사람에게 일을 맡기고, 그 사람이 허용한 데스크톱 기능을 활용하세요.

대상을 지정해 작업 요청

그룹에서 해당 봇을 @ 멘션하거나 Artemis에서 그룹 멤버에게 작업을 할당합니다.

각자의 범위 안에서 작업

컴퓨터마다 프로젝트, 폴더, 파일과 작업 권한을 따로 설정합니다.

요청한 곳으로 결과 반환

위임한 결과는 원래 그룹으로 돌아가 요청자를 멘션하고 후속 작업으로 이어집니다.

자동 위임에는 봇 간 권한 설정과 왕복 통신 검증이 필요합니다. 사람이 다음 봇을 직접 @ 멘션할 수도 있습니다.

사용자 지정 에이전트

나만의 방식을, 믿고 맡길 역할로.

조사, 검토, 글쓰기를 위한 전용 에이전트를 만드세요. 역할과 결과물 기준을 한 번 정하면 선택한 프로젝트에서 반복해서 호출할 수 있습니다.

전용 지침
역할, 작업 방식, 결과물 기준을 정합니다.
모델과 추론
모델과 추론 수준을 지정하거나 현재 대화 설정을 따릅니다.
도구와 프로젝트
사용할 도구와 역할이 적용되는 프로젝트를 선택합니다.
호출 방식
데스크톱에서 @로 지정하거나 주 에이전트의 자동 선택을 허용합니다.

검토 담당

@

하나의 역할이 여러 작업에 참여할 수 있습니다.

함께 쓸 때 넓어지는 가능성

하나의 방식, 두 가지 협업.

사용자 지정 에이전트가 전문성을 더하고, Agent Team이 한 컴퓨터의 분담을 조율합니다. IM 그룹은 각자의 Artemis를 연결합니다.

전문 역할을 하나의 팀으로.

조사와 검토를 독립된 작업으로 나눠 사용자 지정 에이전트가 병렬로 진행합니다. 주 에이전트가 진도를 조율하고 결과를 모으며, 팀 패널에서 각 역할을 확인할 수 있습니다.

  1. 01

    작업 나누기

    각 부분에서 필요한 결과를 정합니다.

  2. 02

    전문 역할 호출

    @ 작업 블록이나 허용한 자동 호출을 사용합니다.

  3. 03

    병렬로 진행

    Agent Team에서 담당, 상태, 메시지를 확인합니다.

  4. 04

    결과 모으기

    각 역할의 결과를 현재 작업으로 가져옵니다.

그룹의 요청 하나, 뒤에서 움직이는 팀.

로컬 역할의 자동 호출을 켜 두면, 그룹 작업이 해당 Artemis에 도착했을 때 주 에이전트가 프로젝트 범위 안에서 역할을 선택합니다. 각자의 컴퓨터가 맡은 부분을 처리하고 공동 대화로 결과를 돌려줍니다.

  1. 01

    그룹에서 요청

    허용된 봇에 목표를 전달합니다.

  2. 02

    멤버에게 할당

    적합한 작업을 해당 멤버의 Artemis에 맡깁니다.

  3. 03

    로컬에서 분담

    주 에이전트가 사용할 수 있는 전문 역할로 팀을 구성합니다.

  4. 04

    그룹에 답장

    결과를 모아 요청자에게 답하고 협업을 이어갑니다.

완전한 데스크톱 작업 공간

끝까지 마무리할 도구도, 팀 곁에 있습니다.

프로젝트와 대화

작업의 흐름을 이어 가세요.

대화를 저장, 검색, 보관하고 분기하세요. 프로젝트 작업은 로컬 파일과 이어지고 임시 대화는 독립적인 작업 공간을 제공합니다. 목표 기능으로 긴 작업을 이어 가며 토큰 예산도 설정할 수 있습니다.

파일과 문서

계속 활용할 수 있는 결과를.

파일을 읽고 편집하고 Markdown을 미리 보세요. 기본 플러그인으로 Word, Excel, PowerPoint, PDF를 만듭니다. 기본 내용을 지원하며 매크로, 애니메이션, 복잡한 배치의 완전한 보존은 보장하지 않습니다.

코드와 검토

전달하기 전에 변경을 이해하세요.

지난 턴, 스테이징된 변경, 브랜치를 비교하고 줄별 의견과 부분 스테이징을 활용하세요. 로컬 체크아웃이나 명시적으로 선택한 분리된 워크트리에서 작업할 수 있습니다.

터미널과 브라우저

확인할 근거를 가까이.

실제 터미널, 웹페이지와 파일을 대화 옆에서 확인하세요. 브라우저의 웹 콘텐츠는 데스크톱 API 및 로컬 파일과 분리됩니다.

자동화

일상적인 일에 규칙적인 시간을.

일회성, 일정 간격, 매일 또는 매주 작업을 시간대와 함께 예약하고 이력을 확인하세요. Artemis가 켜진 동안 실행되며 실행 모드 자동화에는 명시적인 승인이 필요합니다.

플러그인과 서비스

필요한 기능만 더하세요.

플러그인, 스킬, 커넥터와 MCP를 한곳에서 관리하세요. MCP 서버를 찾고 계정을 연결하거나 신뢰하는 마켓을 추가할 수 있습니다. 외부 마켓은 기본으로 가져오지 않습니다.

모델과 사용량

나에게 맞는 균형을.

대화별 모델과 호환 공급자를 선택하고 토큰 및 캐시 사용량을 확인하세요. Ultra 모드는 복잡한 작업에 깊은 추론과 병렬 작업을 제공하며 사용량도 늘어납니다.

기억과 언어

반복은 줄이고, 흐름은 이어 가세요.

프로젝트 지식과 지침을 재사용하세요. 스킬과 도구 설정을 선택해 가져오며 자격 증명을 몰래 복사하지 않습니다. 14개 언어, 시스템 언어와 아랍어의 오른쪽에서 왼쪽 배치를 지원합니다.

명확함에서 시작되는 안심.

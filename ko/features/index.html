Plan · Work · Codemode

계획에서 완성까지.

먼저 계획하고, 바로 작업하거나 Codemode로 도구를 연결하세요. 파일과 결과, 결정을 한 작업 공간에 모읍니다.

  1. 1

    Plan

    파일을 바꾸지 않고 조사하고 검토합니다. Plan은 Shell, MCP, 실행 가능한 확장 기능을 사용하지 않으며 실행 시점은 사용자가 결정합니다.

  2. 2

    Work

    선택한 승인 정책에 따라 파일을 편집하고 도구를 실행합니다. Work는 새 작업의 기본 모드입니다.

  3. 3

    Codemode

    스크립트로 도구를 연결해 여러 단계의 작업을 진행합니다. Codemode는 Work와 같은 권한 및 승인 규칙을 따릅니다.

대화 안에서 확인하는 결과.

이미지, 움직이는 SVG, 오디오, 동영상, Mermaid, LaTeX를 표시합니다. 로컬 HTML은 격리되어 실행되며 Office와 PDF 카드는 측면 뷰어를 엽니다.

나에게 맞는 작업 공간.

스킨 플러그인을 미리 보고 적용하거나 기본값으로 복원하세요. 지원 스킨은 밝고 어두운 배경, 무음 동영상, 글꼴, 아이콘 및 동작 줄이기를 제공합니다.

필요한 순간에 익숙한 작업 흐름을.

설정에서 명령 Hooks를 검토하고 명시적으로 신뢰하세요. Work와 Codemode에서 실행되며 Plan에서는 건너뜁니다. 플러그인, Skills, MCP는 리소스 센터에서 관리합니다.

대화형 플러그인

격리된 패널과 도구를 추가하세요. Design 플러그인이 설치되어 사용 가능한 경우 문서 작성, 버전 기록, 실행 취소 및 복원을 지원합니다. 프로젝트 파일은 명시적으로 가져와야 합니다.

Office · DOCX / XLSX / PPTX / CSV

대화 옆에서 문서를 완성하세요.

Office 작업대에서 Word, Excel, PowerPoint 파일을 미리 보고 편집하며 주석을 달 수 있습니다. 직접 편집은 로컬에서 처리되며 자동 저장과 실행 취소·다시 실행을 지원합니다.

Office 미리 보기에는 선택적 Office 구성 요소 설치 및 활성화가 필요합니다. 기본 문서 플러그인은 별도로 사용할 수 있습니다.

Documents, Presentations 또는 Spreadsheets에서 Office 업그레이드를 선택해 공용 선택 구성 요소를 온라인으로 설치하거나 .artemis-office 파일을 가져오세요. macOS Apple Silicon과 Windows x64를 지원하며 편집과 저장에는 Work / Codemode 모드가 필요합니다.

Office 파일은 작업 사본에 저장되어 원본을 보존합니다. 외부 변경과 충돌하면 덮어쓰기를 차단합니다. 지원되는 텍스트와 셀을 편집하는 기능으로, 전체 Office 레이아웃 편집기는 아니며 복잡한 서식은 달라질 수 있습니다.

  1. 1

    Word와 PowerPoint

    고유하게 식별할 수 있는 DOCX 문단과 PPTX 개체 텍스트를 바로 편집하세요. 확대·축소와 슬라이드 썸네일로 결과를 확인합니다.

  2. 2

    Excel과 CSV

    각 시트의 A1:Z50 범위에서 XLSX 값과 수식을 편집하고 표와 인쇄 미리 보기를 전환하세요. CSV는 셀 및 원문 편집을 지원하며 충돌 확인 후 UTF-8 원본에 저장합니다.

  3. 3

    위치를 지정하고 수정 요청하기

    텍스트 대상, 셀 또는 페이지 영역을 선택하고 주석을 추가하세요. 선택 영역과 문서 버전이 피드백과 함께 입력창에 표시되며 직접 확인해 전송합니다.

화면으로 보는 Office.

스크린샷은 예제 데이터를 사용하며 현재 출시 버전과 다를 수 있습니다.

Computer Use · macOS 14+

한마디 요청을 화면 속 작업으로.

Artemis가 내장 브라우저에서 양식을 작성하고, 컨트롤을 클릭하고, 웹페이지를 탐색하며 Mac 앱도 조작합니다.

macOS 14 이상이 필요합니다. 네이티브 앱에는 손쉬운 사용 및 화면 기록 권한도 필요합니다. Windows는 지원하지 않습니다.

브라우저에서 이 신청서를 작성하고 내가 확인할 수 있게 해 줘.
  1. 1

    몇 단계면 준비 완료

    리소스 센터의 기본 제공 플러그인에서 Computer Use를 설치하세요. Work / Codemode에서 이미지를 지원하는 모델을 선택하고 작업을 설명하면 됩니다. 별도의 모델 키는 필요하지 않습니다.

  2. 2

    제어권은 언제나 사용자에게

    앱별 접근을 승인하고 언제든 중지하세요. 포그라운드 제어에는 별도 승인이 필요하며 저장된 앱 권한도 취소할 수 있습니다.

IM 연결

책상 밖에서도, 작업은 이어집니다.

자신의 봇과 직접 대화하며 프로젝트 확인과 파일 작업을 맡기고 결과를 받으세요. 같은 대화에서 질문을 이어가고, 확인 요청이나 본인 승인도 처리할 수 있습니다.

Feishu / Lark
Feishu는 QR 연결과 스트리밍 카드 답장을 지원합니다. Lark는 수동으로 설정할 수 있습니다.
Slack
봇과의 개인 메시지로 로컬 작업을 연결하고 채널에서 협업합니다.

작업을 받으려면 컴퓨터가 깨어 있고 Artemis와 연결이 활성화되어 있어야 합니다.

메시지에서 로컬 작업으로

“프로젝트를 확인하고 오늘의 진행 상황을 정리해 줘.”
  1. 1

    메시지로 시작

    평소 사용하는 메시지 도구에서 요청합니다.

  2. 2

    내 컴퓨터에서 처리

    허용한 프로젝트, 파일, 도구를 사용합니다.

  3. 3

    원래 대화로 돌아오기

    진행 상황과 결과를 받고 다음 질문을 이어갑니다.

Artemis

IM 그룹 협업

같은 대화에, 각자의 강점을.

기존 Slack 채널이나 Feishu / Lark 그룹에서 각자가 자신의 봇과 Artemis를 연결합니다. 알맞은 사람에게 일을 맡기고, 그 사람이 허용한 데스크톱 기능을 활용하세요.

대상을 지정해 작업 요청

그룹에서 해당 봇을 @ 멘션하거나 Artemis에서 그룹 멤버에게 작업을 할당합니다.

각자의 범위 안에서 작업

컴퓨터마다 프로젝트, 폴더, 파일과 작업 권한을 따로 설정합니다.

요청한 곳으로 결과 반환

위임한 결과는 원래 그룹으로 돌아가 요청자를 멘션하고 후속 작업으로 이어집니다.

자동 위임에는 봇 간 권한 설정과 왕복 통신 검증이 필요합니다. 사람이 다음 봇을 직접 @ 멘션할 수도 있습니다.

사용자 지정 에이전트

나만의 방식을, 믿고 맡길 역할로.

조사, 검토, 글쓰기를 위한 전용 에이전트를 만드세요. 역할과 결과물 기준을 한 번 정하면 선택한 프로젝트에서 반복해서 호출할 수 있습니다.

전용 지침
역할, 작업 방식, 결과물 기준을 정합니다.
모델과 추론
모델과 추론 수준을 지정하거나 현재 대화 설정을 따릅니다.
도구와 프로젝트
사용할 도구와 역할이 적용되는 프로젝트를 선택합니다.
호출 방식
데스크톱에서 @로 지정하거나 주 에이전트의 자동 선택을 허용합니다.

이런 역할로 나눌 수 있어요

01

조사 담당

자료와 출처를 정리하고 근거 있는 결론을 도출합니다.

@
02

검토 담당

논거와 누락을 확인하고 구체적인 개선안을 제시합니다.

@

하나의 역할이 여러 작업에 참여할 수 있습니다.

함께 쓸 때 넓어지는 가능성

하나의 방식, 두 가지 협업.

사용자 지정 에이전트가 전문성을 더하고, Agent Team이 한 컴퓨터의 분담을 조율합니다. IM 그룹은 각자의 Artemis를 연결합니다.

전문 역할을 하나의 팀으로.

조사와 검토를 독립된 작업으로 나눠 사용자 지정 에이전트가 병렬로 진행합니다. 주 에이전트가 진도를 조율하고 결과를 모으며, 팀 패널에서 각 역할을 확인할 수 있습니다.

  1. 01

    작업 나누기

    각 부분에서 필요한 결과를 정합니다.

  2. 02

    전문 역할 호출

    @ 작업 블록이나 허용한 자동 호출을 사용합니다.

  3. 03

    병렬로 진행

    Agent Team에서 담당, 상태, 메시지를 확인합니다.

  4. 04

    결과 모으기

    각 역할의 결과를 현재 작업으로 가져옵니다.

그룹의 요청 하나, 뒤에서 움직이는 팀.

로컬 역할의 자동 호출을 켜 두면, 그룹 작업이 해당 Artemis에 도착했을 때 주 에이전트가 프로젝트 범위 안에서 역할을 선택합니다. 각자의 컴퓨터가 맡은 부분을 처리하고 공동 대화로 결과를 돌려줍니다.

  1. 01

    그룹에서 요청

    허용된 봇에 목표를 전달합니다.

  2. 02

    멤버에게 할당

    적합한 작업을 해당 멤버의 Artemis에 맡깁니다.

  3. 03

    로컬에서 분담

    주 에이전트가 사용할 수 있는 전문 역할로 팀을 구성합니다.

  4. 04

    그룹에 답장

    결과를 모아 요청자에게 답하고 협업을 이어갑니다.

완전한 데스크톱 작업 공간

Artemis

중요한 일에 집중할 여유.

무언가를 만들고, 질문을 탐구하고, 생각을 글로 옮기세요. Artemis가 AI와 파일, 필요한 도구를 한곳에 모아 작업의 흐름을 이어 줍니다.

Windows 11 · macOS 14+ · 14개 언어

호기심에서 결과물까지

당신이 마음 쓰는 일을 위해.

하나의 프로그램. 읽을 만한 보고서. 조금 더 생각해 보고 싶은 질문.

01

개발과 다듬기

아이디어를 끝까지 이어 가세요.

코드를 이해하고 수정한 뒤 명령을 실행하고 변경 사항을 검토하세요. 파일, 터미널, 브라우저 옆에서 대화를 이어 갑니다.

02

조사와 창작

생각을 쓸모 있는 형태로.

자료를 모아 문서를 쓰고, 표를 정리하고, 발표 자료를 만드세요. 프로젝트가 필요 없다면 임시 대화로 시작하면 됩니다.

나에게 맞는 작업 공간

나만의 속도. 나만의 선택.

연속성

하던 곳에서 다시 시작하세요.

저장된 대화로 돌아오고, 생각을 새 작업으로 분기하며, 유용한 프로젝트 지식을 가까이 두세요.

선택

함께 생각할 방법을 고르세요.

대화마다 모델, 추론 수준과 컨텍스트 한도를 설정하고 모델 사용량을 한곳에서 확인하세요.

제어

행동할 때를 직접 정하세요.

계획과 검토 모드는 파일을 바꾸지 않습니다. 준비가 되면 실행 모드로 전환해 작업을 진행하세요.

작업에 맞는 도구

익숙한 방법을 가져오세요.

리소스 센터에서 필요한 기능을 추가하세요. 도움이 되는 것은 남기고, 쓰지 않는 것은 끌 수 있습니다.

문서

메모에서 전달할 파일까지.

기본 도구로 Word, Excel, PowerPoint, PDF의 기본 내용을 읽고 만듭니다. 복잡한 서식은 달라질 수 있습니다.

스킬

잘되는 방법은 다시 쓰세요.

지침, 프로젝트 기억, 전문 에이전트를 재사용해 같은 작업 방법을 반복해서 설명할 필요를 줄입니다.

연결

이미 쓰는 도구와 함께.

서비스와 MCP 도구를 연결하고, 연결 상태와 권한을 확인하고 관리하세요.

작업 과정을 눈앞에.

분리된 예제 프로젝트와 시연 데이터를 사용한 실제 Artemis 화면입니다.

01

변경 하나하나를 살펴보세요.

대화 옆에서 코드를 검토하고, 줄에 의견을 남기거나 파일과 변경 부분을 선택해 스테이징하세요.

02

각자의 역량을 같은 대화로.

Slack이나 Feishu / Lark 그룹에 각자의 Artemis를 연결하세요. 허용한 봇에 일을 맡기고 같은 대화에서 결과를 받습니다.

03

반복되는 일에 일정한 리듬을.

조사 요약이나 프로젝트 점검을 예약하세요. 로컬 자동화는 실행 이력을 남기며 Artemis가 켜져 있을 때 동작합니다.

Google 도구를 내 작업에 연결하세요.

승인하면 Artemis가 Gmail 검색과 초안 작성, Google Drive 파일 작업, Google Calendar 일정 관리를 돕습니다. 관련 내용은 설정한 모델 서비스에 전송될 수 있습니다. 계정 연결 전에 개인정보 처리방침을 읽어 주세요.

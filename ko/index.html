개발과 다듬기

아이디어를 끝까지 이어 가세요.

코드를 이해하고 수정한 뒤 명령을 실행하고 변경 사항을 검토하세요. 파일, 터미널, 브라우저 옆에서 대화를 이어 갑니다.

조사와 창작

생각을 쓸모 있는 형태로.

자료를 모아 문서를 쓰고, 표를 정리하고, 발표 자료를 만드세요. 프로젝트가 필요 없다면 임시 대화로 시작하면 됩니다.

Plan · Work · Codemode

계획에서 완성까지.

  1. Plan

    파일을 바꾸지 않고 조사하고 검토합니다. Plan은 Shell, MCP, 실행 가능한 확장 기능을 사용하지 않으며 실행 시점은 사용자가 결정합니다.

  2. Work

    선택한 승인 정책에 따라 파일을 편집하고 도구를 실행합니다. Work는 새 작업의 기본 모드입니다.

  3. Codemode

    스크립트로 도구를 연결해 여러 단계의 작업을 진행합니다. Codemode는 Work와 같은 권한 및 승인 규칙을 따릅니다.

작업 과정을 눈앞에.

스크린샷은 예제 데이터를 사용하며 현재 출시 버전과 다를 수 있습니다.

동영상 미리보기는 소개 영상의 일부이며 예제 데이터와 영어 인터페이스를 사용합니다.

작업에 맞는 도구

익숙한 방법을 가져오세요.

리소스 센터에서 필요한 기능을 추가하세요. 도움이 되는 것은 남기고, 쓰지 않는 것은 끌 수 있습니다.

자세히 알아보기

문서

메모에서 전달할 파일까지.

기본 도구로 Word, Excel, PowerPoint, PDF의 기본 내용을 읽고 만듭니다. 복잡한 서식은 달라질 수 있습니다.

스킬

잘되는 방법은 다시 쓰세요.

지침, 프로젝트 기억, 전문 에이전트를 재사용해 같은 작업 방법을 반복해서 설명할 필요를 줄입니다.

연결

이미 쓰는 도구와 함께.

서비스와 MCP 도구를 연결하고, 연결 상태와 권한을 확인하고 관리하세요.

Computer Use · Windows 11 / macOS 14+

한마디 요청을 화면 속 작업으로.

Artemis가 내장 브라우저에서 양식을 작성하고 컨트롤을 클릭하며 웹사이트를 탐색하거나 Windows와 Mac의 네이티브 앱을 조작하도록 하세요.

Office · Word / Excel / PowerPoint

대화 옆에서 문서를 완성하세요.

Office 작업대에서 Word, Excel, PowerPoint 파일을 미리 보고 편집하며 주석을 달 수 있습니다. 직접 편집은 로컬에서 처리되며 자동 저장과 실행 취소·다시 실행을 지원합니다.

Office 미리 보기에는 선택적 Office 구성 요소 설치 및 활성화가 필요합니다. 기본 문서 플러그인은 별도로 사용할 수 있습니다.

연속성

하던 곳에서 다시 시작하세요.

저장된 대화로 돌아오고, 생각을 새 작업으로 분기하며, 유용한 프로젝트 지식을 가까이 두세요.

선택

함께 생각할 방법을 고르세요.

대화마다 모델, 추론 수준과 컨텍스트 한도를 설정하고 모델 사용량을 한곳에서 확인하세요.

제어

행동할 때를 직접 정하세요.

파일을 바꾸지 않고 조사하고 검토합니다. Plan은 Shell, MCP, 실행 가능한 확장 기능을 사용하지 않으며 실행 시점은 사용자가 결정합니다. 선택한 승인 정책에 따라 파일을 편집하고 도구를 실행합니다. Work는 새 작업의 기본 모드입니다.

Google 도구를 내 작업에 연결하세요.

승인하면 Artemis가 Gmail 검색과 초안 작성, Google Drive 파일 작업, Google Calendar 일정 관리를 돕습니다. 관련 내용은 설정한 모델 서비스에 전송될 수 있습니다. 계정 연결 전에 개인정보 처리방침을 읽어 주세요.

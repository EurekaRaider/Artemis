개인정보와 제어

내 작업 공간. 명확한 경계.

작업이 저장되는 곳과 허용한 범위를 확인하세요. 로컬 저장, 온라인 모델과 연결 도구는 서로 다른 역할을 합니다.

계획 · 실행 · 검토

행동하기 전에 생각할 여유.

계획과 검토 모드는 실행 전에 파일 변경을 차단합니다. 실행 모드는 선택한 승인 정책을 따릅니다. 승인된 셸 명령과 터미널은 데스크톱 사용자 권한으로 동작합니다.

계획검토읽기 전용실행
01

로컬 컨텍스트

기기에 저장하고, 전송도 명확하게.

프로젝트와 대화 이력은 로컬에 저장됩니다. 관련 프롬프트, 파일과 도구 결과는 선택한 모델이나 연결 서비스로 전송될 수 있습니다.

02

자격 증명

운영체제가 보호합니다.

API 키와 연결 자격 증명은 운영체제 암호화를 사용합니다. 보호 기능이 없으면 저장하지 않습니다. 모든 파일과 대화를 암호화한다는 뜻은 아닙니다.

03

도구와 확장

도구마다 별도의 권한.

로컬 MCP 서버는 기본적으로 네이티브 격리를 사용하며 네트워크와 호환 설정을 따로 관리합니다. 실행 확장은 명시적 신뢰가 필요하고 전체 로컬 접근 설정은 확장에만 적용됩니다.

04

IM 권한

선택한 범위에서 일을 나누세요.

대상별로 프로젝트, 폴더나 파일을 허용합니다. 쓰기, 명령과 네트워크 권한은 별도입니다. 그룹 가입만으로 컴퓨터 접근을 허용하지 않습니다.

이해한 뒤 연결하세요.

민감한 정보를 다루기 전에 계정 연결, 모델 처리, 보관과 삭제 방법을 확인하세요.

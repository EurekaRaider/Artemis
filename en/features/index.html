Plan · Work · Codemode

From a plan to finished work.

Plan first, work directly, or coordinate tools with Codemode. Keep files, results and your decisions in the same workspace.

  1. 1

    Plan

    Investigate and review without changing files. Plan cannot run Shell, MCP or executable extensions; you choose when to proceed.

  2. 2

    Work

    Edit files and run tools under the selected approval policy. Work is the default for new tasks.

  3. 3

    Codemode

    Coordinate tools through scripts for multi-step work. Codemode follows the same permissions and approvals as Work.

Office · DOCX / XLSX / PPTX / CSV

Your documents. Right beside the conversation.

Preview, edit and annotate Word, Excel and PowerPoint files in the Office workbench. Manual edits run locally, with autosave and undo/redo.

Office preview requires the optional Office component to be installed and active. Basic document plugins are available separately.

In Documents, Presentations or Spreadsheets, choose Upgrade Office to install the shared optional component online or import a .artemis-office file. Available on macOS Apple Silicon and Windows x64; editing and saving require Work / Codemode mode.

Office files save to a working copy, preserving the original. External changes block conflicting saves. Editing covers supported text and cells, not full Office layout editing; complex formatting may differ.

  1. 1

    Word & PowerPoint

    Edit uniquely identifiable DOCX paragraphs and PPTX object text in place. Review pages with zoom and slide thumbnails.

  2. 2

    Excel & CSV

    Edit XLSX values and formulas within A1:Z50 on each sheet; switch between the grid and print preview. CSV supports cell and source editing and saves back to the UTF-8 original after conflict checks.

  3. 3

    Point to the change

    Select text targets, cells or a page region and add a note. The selection and document version accompany your feedback in the composer, ready for you to send.

Computer Use · macOS 14+

From a request to action on screen.

Let Artemis fill forms, click controls and navigate websites in its built-in browser or work with Mac apps.

Requires macOS 14 or later. Native apps also need Accessibility and Screen Recording permissions. Not available on Windows.

Fill in this registration form in the browser, then let me review it.
  1. 1

    Ready in a few steps

    Install Computer Use from bundled plugins in the resource center. In Work / Codemode, choose an image-capable model and describe the task. No extra model key is needed.

  2. 2

    You stay in control

    Approve access per app and stop at any time. Foreground control needs separate permission; saved app permissions can be revoked.

IM group collaboration

One conversation. Everyone’s strengths.

In an existing Slack channel or Feishu / Lark group, each member connects their own bot and Artemis. Send work to the right person and the desktop capabilities they have chosen to share.

Give work to a specific member

Mention their bot in the group, or assign a task to a group member from Artemis.

Keep each person’s scope clear

Each computer grants access to its own projects, folders, files and operations.

Bring results back to the request

Delegated results return to the source group and mention the requester, ready for the next step.

Automatic delegation requires bot authorization and a verified round trip. People can also mention the next bot manually.

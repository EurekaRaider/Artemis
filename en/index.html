Plan · Work · Codemode

From a plan to finished work.

  1. Plan

    Investigate and review without changing files. Plan cannot run Shell, MCP or executable extensions; you choose when to proceed.

  2. Work

    Edit files and run tools under the selected approval policy. Work is the default for new tasks.

  3. Codemode

    Coordinate tools through scripts for multi-step work. Codemode follows the same permissions and approvals as Work.

Windows 11 · macOS 14+

A workspace, not a chat box

Built for work, not just code.

Artemis keeps the task, the tools, and the evidence together so the Agent can help with work that continues beyond one prompt.

01

Development

Move from repository context to reviewed change.

Keep implementation, terminal output, browser checks, and Git review attached to the same persistent task.

02

Everyday work

Research, write, and coordinate in one place.

Use connected capabilities for documents, services, and recurring work without turning the desktop into a pile of disconnected tabs.

03

Local by default

Keep the working context on your machine.

Artemis is a desktop workspace. Local projects, task history, and user-opened tools remain close to the files they act on.

Designed for trust

Clear state. Clear boundaries.

Local-first

The workspace starts on your device.

Projects and task context are organized around the checkout you choose, not a hidden remote workspace.

Replayable

Important UI events can be rebuilt deterministically.

Persisted events use versioned envelopes and idempotent reducers, creating an auditable history instead of fragile transient state.

Explicit trust

Capability follows mode and source trust.

Read-only modes stay read-only. Executable extensions remain off until the project and content hash are trusted.

Pi-powered

One Agent loop. More ways to work.

Pi is the single Agent loop in Artemis. Plugins, Skills, and MCP servers expand what that loop can do without adding a second hidden orchestrator.

Plugins

Add product capabilities.

Install reviewed integrations and artifact workflows from one visible resource center.

Skills

Bring focused operating guidance.

Give the Agent reusable instructions for a workflow while keeping current requests and policy higher priority.

MCP

Connect local or remote tools.

Use per-server network, environment, and sandbox controls for enabled local stdio servers.

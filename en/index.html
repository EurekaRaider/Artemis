A workspace that feels like yours

Your pace. Your choices.

Continuity

Pick up where you left off.

Return to saved conversations, branch an idea into a new task, and keep useful project knowledge close.

Choice

Choose how you think together.

Set a model, reasoning level and context limit for each conversation. See model usage in one place.

Control

Decide when to act.

Investigate and review without changing files. Plan cannot run Shell, MCP or executable extensions; you choose when to proceed. Edit files and run tools under the selected approval policy. Work is the default for new tasks.

Tools that fit the task

Bring your way of working.

Documents

From notes to a deliverable.

Bundled tools read and create Word, Excel, PowerPoint and PDF files. Basic content is supported; complex formatting may change.

Skills

Keep the methods that work.

Connections

Work with your existing tools.
